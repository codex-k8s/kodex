# Открытые решения владельца

Здесь хранятся решения, без которых нельзя однозначно реализовать требования.
Документ не подменяет Issue и не расширяет scope.

## Формат

### GOV-OD-001. Название

- адресат: owner / заказчик / architect;
- затронутые документы: `...`;
- статус: `открыт` / `закрыто`;
- рекомендуемый вариант: `...`;
- альтернативы: `...`;
- временная предпосылка до решения: `...`;
- что синхронизировать после решения: docs, contracts, backlog, code,
  configuration, acceptance.

### GOV-OD-003. Число рецензентов в локальном dogfooding #1796

- адресат: owner;
- затронутые документы: `AGENT-DOC-001`, `GUIDE-DOC-004`, `GOV-DOC-003`,
  `OPS-DOC-SELFDEV-001`, #1796, #1797;
- статус: `закрыто`;
- источник: явное решение владельца от08.10.2026 «пусть одно ревью»,
  зафиксированное в `OPS-DOC-SELFDEV-001`, раздел «Обязательный checklist»;
- выбранный вариант: для этого локального экспериментального SOFTWARE_CHANGE
  Manager → Architect → Developer → один независимый комплексный рецензент
  фактического diff на точном SHA → продуктовая приёмка Manager → исправления
  и повторное комплексное ревью нового SHA, до пяти циклов после первоначального
  review → единственный финальный Human Gate владельца;
- покрытие: комплексный рецензент проверяет архитектуру, безопасность,
  документацию и лексику; Manager независимо проверяет продуктовые требования.
  Все применимые обязательные проверки, authority/lifecycle invariants и
  запрет выдавать NOT RUN за PASS остаются прежними;
- граница: только локальный dogfooding по #1796 в bootstrap #1797. Не выдаёт
  роли дополнительные полномочия, не разрешает пропуск замечаний или gate,
  не распространяется автоматически на иные задачи и production. Конечный
  бизнес-PR передаётся владельцу, без merge/auto-merge/owner approve агентами;
- что синхронизировано: применимость исключения в AGENTS, delivery guide и
  стратегии проверок; экспериментальный Workflow уже имеет один review.
  Доступность новой документации через закреплённый main и повторный readback
  рабочего пути проверяются отдельно, не предполагаются из этой записи.
