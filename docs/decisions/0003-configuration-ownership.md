# ADR-MC-003. Владение конфигурацией UI и GitOps

## Решение

Центр управления и версионируемый каталог YAML поддерживаются одновременно. Каждая управляемая сущность имеет `managed_by: ui|git`, ссылку на источник и ревизию.

- Объект под управлением Git доступен в интерфейсе только для чтения, кроме явного отсоединения или создания копии.
- Объект под управлением интерфейса можно экспортировать в YAML и передать под управление Git.
- Значения секретов отсутствуют в YAML; используются ссылки на учетные данные.
- Контроллер идемпотентно применяет желаемое состояние Git и показывает расхождение и состояние.

## Причина

Конфигурация только через YAML исключает бизнес-пользователей, а только через интерфейс не дает воспроизводимость системным интеграторам. Двусторонняя запись без явного владельца создает конфликты и потерю изменений.
