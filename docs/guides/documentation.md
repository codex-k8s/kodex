# Документация и инструкции агентов

## Метаданные

Активный документ имеет метаданные front matter со стабильными полями `id`, `title`, `type`, `status`, `owner`, `version` и датой `updated`.

Допустимые статусы: `draft`, `proposed`, `approved`, `superseded`, `archived`.

## Источник истины

- Поведение продукта - `docs/product`.
- Системная архитектура - `docs/architecture` и ADR.
- Владение доменами - `docs/domains`.
- Правила реализации - `docs/guides` и детальные инженерные руководства.
- Эксплуатация — `docs/operations` и пошаговые инструкции.
- План развития - `docs/roadmap`.

Документ не копирует правило другого раздела без ссылки и объяснения локального контекста.

## Изменения

- Существенное решение обновляет продуктовую, доменную и архитектурную документацию и ADR в одном цикле результата.
- Код не принимается, если он расходится с утвержденными документами без отдельного ADR.
- `improver` обновляет инструкции и руководства только отдельным проверяемым предложением.
- Исторический документ получает `superseded` и ссылку на замену.

## Язык

Проектные документы, Issues, PR и комментарии рецензирования по умолчанию пишутся на выбранной локали проекта или пользователя, если `AGENTS.md` не задает более конкретное правило. Комментарии в коде следуют тому же правилу. Идентификаторы кода и неизменяемые термины внешних API не переводятся искусственно.

В обычной русской прозе используются русские слова: владелец, менеджер, исполнитель, рецензент, рабочая область, комната, обсуждение, сессия, ход, поставщик, интеграция, согласование, расписание, очередь, обратный вызов, среда выполнения, развертывание, резервное копирование и восстановление.

Английская форма допустима:

- внутри идентификатора, команды, пути, конфигурации или фрагмента кода;
- при первом определении доменной сущности, например `RuntimeRevision`;
- для названия продукта, протокола или общепринятого формата: Mattermost, OpenAI Codex, MCP, OpenAPI, AsyncAPI, gRPC, S3;
- когда перевод изменит точный смысл внешнего контракта или канонического статуса.

Смесь вроде «owner запускает reviewer для review result» в проектной прозе запрещена. Правильная форма: «владелец запускает рецензента для проверки результата».

## Инструкции агентов

`InstructionSet` должен быть коротким индексом со ссылками на релевантные документы. Нельзя копировать весь корпус в промпт. Материализатор среды выполнения передает манифест и дает агенту читать нужные файлы.
