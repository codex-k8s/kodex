# Финальная отладка локального прототипа Kodex

Область: локальный `trusted-cluster`, клон
`/home/s/projects/matter-codex`, Issue #1784 и PR #1785. Этот документ задаёт
порядок оставшихся этапов. Хронологические доказательства и найденные дефекты
фиксируются в `docs/operations/assistant-prototype-debug-1763.md`.

## Правила выполнения

- Этапы выполняются строго сверху вниз и без остановки между ними.
- Если нужен продуктовый выбор, применяется безопасный рекомендуемый вариант;
  вопрос владельцу не блокирует переход к следующему доступному этапу.
- Работа ведётся в текущей ветке и PR #1785. Слияние — только по отдельной
  команде владельца.
- Используется локальный кластер и прямой read-only mount исходников для
  Air/Vite hot reload. Образы пересобираются только когда hot reload
  недостаточен.
- После каждого этапа выполняются адресные проверки, reload без кэша в уже
  открытой вкладке Kodex через Chrome DevTools MCP, проверка console,
  network 4xx/5xx, пользовательского сценария и итоговый screenshot.
- Завершённый этап получает `[x]` только после проверяемого результата. Затем
  обновляются этот checklist и журнал, изменения фиксируются коммитом и
  отправляются в тот же PR.
- Фикстуры не пересоздаются. В локальном Keycloak разрешено создавать нужные
  тестовые аккаунты, роли и группы без раскрытия credential values.
- Русские и английские пользовательские тексты обновляются вместе. Desktop
  проверяется на 1920×1080; мобильная доводка не входит в эту волну.
- Проверка STT, повторная device-code авторизация и восстановление после reboot
  выполняются владельцем и в этот план не входят.

## Этапы

- [x] **1. Завершить текущий незакоммиченный пакет.** Исправить перепривязку
  runtime-сессии при переходе глобального диалога в Проект; завершить защиту
  модалки отзыва секрета от схлопывания текста; проверить hot reload и точный
  browser-сценарий; обновить журнал, закоммитить и отправить пакет в PR #1785.

- [x] **2. Закончить каскадную корзину непустого Проекта.** Перенести Проект с
  `cascade-proof.md` в корзину, проверить скрытие дочерних объектов,
  восстановить всё содержимое, повторно удалить и выполнить безвозвратное
  удаление; проверить repo-owned очистку объектов старше 30 дней.

- [x] **3. Завершить варианты помощника и штатные формы.** Проверить
  независимые варианты создания и изменения оставшихся типов сущностей,
  сохранение всех вариантов в истории, открытие заполненной штатной формы
  поверх чата, редактирование, применение любого совместимого варианта,
  OCC-конфликты и возврат к прежнему варианту.

- [x] **4. Завершить образы и сборку.** Проверить остановку сборки,
  воспроизвести terminal-ошибку, передать сотруднику безопасный журнал для
  исправления и устранить либо точно локализовать причину неготовности старого
  образа «Разработчик Marketplace».

- [x] **5. Завершить окружения и секреты.** Проверить разрешённое чтение
  секрета внутри Run, закрытый отказ без необходимого полномочия и полный
  сценарий отзыва секрета с устойчивым error-состоянием модалки.

- [x] **6. Завершить Процессы и запуски.** Проверить остановку и повтор
  Процесса, конфликт версий, живой terminal-сбой дочерней работы, передачу
  диагностики сотруднику и конкурентный `claim/terminal`.

- [x] **7. Завершить автоматизации.** Проверить фактический запуск по
  расписанию, появление выполнения в истории, паузу, возобновление и расчёт
  следующего запуска.

- [x] **8. Завершить OpenAPI/MCP.** Выполнить WRITE через вновь созданное
  подключение, проверить отрицательные сценарии credential, разрешений и

  набора аргументов.

- [x] **9. Завершить файлы, навыки и память.** Проверить cursor-дозагрузку
  второй страницы навыков и памяти, создание бинарного файла через помощника,
  оставшиеся состояния публикации и архивации.

- [x] **10. Завершить участников и доступ.** Создать в локальном Keycloak

- [x] **11. Завершить учётные записи и конфигурации.** Пройти оставшиеся
