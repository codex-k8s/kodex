# Ошибка ограничения распознавания речи

Refs #1045, #1020, #1088, #1031.

Оба HTTP маршрута транскрипции сохраняют ошибку авторитетного STT:
`ResourceExhausted` с `ErrorInfo.domain=kodex.stt` и
`reason=TRANSCRIPTION_RATE_LIMITED` становится HTTP 429 с тем же кодом.
Проверенные полномочия, потоковая передача и receipt успешной операции
не меняются. Ошибка не создаёт receipt успеха и не инициирует повторный POST.

Единственная корректная подсказка провайдера переводится в `RetryInfo`, затем
в `Retry-After`: целое число секунд от 1 до 300. HTTP-date округляется вверх.
Отсутствующие, повторённые, некорректные и превышающие предел значения
не сокращаются: ответ остаётся типизированным, но без заголовка и с
`retryable=false`. При корректной подсказке `retryable=true` означает
возможность явного действия пользователя после указанного срока, а не
разрешение автоматического повторного платного запроса. Локальное ограничение
квоты сохраняет прежний `RATE_LIMITED`.

Тело ответа провайдера, аудио, транскрипция и credential не входят в ошибку.
Раннее закрытие gRPC Send получает окончательный статус через CloseAndRecv;
оно проходит тот же mapper, что и обычное завершение потока.

Проверка вручную в разрешённой тестовой среде: вернуть из защищённого fake
provider 429 с Retry-After 17, затем без заголовка и со значением 301. Проверить
оба HTTP маршрута, точный код, наличие заголовка только в первом случае и один
provider POST на действие. Live-провайдер для этой проверки не требуется.

Регрессии покрывают оба маршрута, раннее закрытие, отсутствие подсказки,
границы, дробное/отрицательное значение, дубли RetryInfo и чужой error domain.
Локальные результаты фиксируются отдельно на точном commit; staging/live,
общее review, merge и deployment этой проверкой не подтверждаются.

На исходном producer `9d9d8ba2b5c91b902373e06edaf53770db11150e` полный
STT race/vet/build прошёл локально; живой provider не вызывался. HTTP scoped
Speech/Transcribe race прошёл за 1.083 с, canonical Go/TS/AsyncAPI и strict SDK
также прошли. Первый расширенный запуск выявил устаревшую отрицательную
fixture фильтра DELETED; она перенесена в положительную матрицу допустимого
owner enum. Это исторический FAIL, а не ошибка распознавания речи.
Повтор Speech/Transcribe/CatalogFilters прошёл за 1.124 с; повторная каноническая
генерация Go/TS/AsyncAPI побайтно совпала с первым результатом.

Проверены Context7 `/websites/developers_openai_api` и официальная
[документация ошибок OpenAI](https://developers.openai.com/api/docs/guides/error-codes).
Откат — согласованный возврат HTTP и STT изменений; он восстанавливает прежний
обобщённый ответ и теряет точную подсказку провайдера.
