Выбрано: Офисные документы и PDF · rev 4 (текущее)

Окружение выбирается через async picker, рассчитанный на десятки и сотни рецептов: серверный поиск с debounce, состояния loading / empty / error (запрос «ошибка»), cursor-пагинация с infinite scroll и footer «Показано N из M». В каждой строке — иконка, назначение, инструменты, ревизия, состояние сборки образа и совместимость с runtime; несовместимые и несобранные окружения отключены с подсказкой. Текущее окружение выделено, кнопка «Выбрать» активна только при изменении выбора.
