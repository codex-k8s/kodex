Пакет описывает типизированные инструменты. Произвольные shell-команды недопустимы; версия неизменяема, изменения публикуются новой версией. Секреты в пакете отсутствуют — только схема подключения и ссылки на credential.

Пакет показан как управляемое описание возможностей: таблица capabilities раскрывает назначение, класс риска (цвет + текст), режим чтение/запись, требование Human Gate, bounded result и доступные resource scopes. Справа — read-only YAML без секретов; версия неизменяема, действие «Изменить» отключено с пояснением. Подключения и версии вынесены во вкладки.
