Окружения — реестр рецептов образов роли (RoleImageRecipe) в области Проекта плюс общие окружения организации (их правка — только в Администрировании). Для каждого рецепта видны назначение, базовый образ человеческим именем, инструменты, ревизия, состояние сборки и допуска (готово, собирается с прогрессом, ждёт допуска, ошибка, несовместимо, черновик) и связанные сотрудники. Панель деталей показывает чек-лист проверок цепочки поставки (provenance, SBOM, уязвимости, подпись, закреплённый digest) без значений digest и адресов реестра, ревизии со сравнением и кто когда перейдёт на новую ревизию.
