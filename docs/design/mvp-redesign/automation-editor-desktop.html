Повторять

Редактор автоматизации — одна страница-форма с липкой сводкой «Что изменится». Расписание задаётся пресетом или cron с часовым поясом; некорректное выражение показывается как ошибка поля (иконка + текст, не только цвет), блокирует сохранение и не влияет на действующую версию v3. Цель выбирается async picker сотрудников, входные файлы — multi picker с фиксацией точной версии. Политика сессии, пропусков и параллельности — явные controls. Сохранение создаёт v4 только для будущих запусков.
