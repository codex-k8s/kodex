Состояние проверки
Источник

Выбран radio «Продолжить существующую сессию»: под ним появился combobox с выбранной сессией (название до двух строк, ниже сотрудник, время, число ходов и итог) и открыт async picker фиксированной ширины 480 px. Для Процесса предлагаются только завершённые сессии его координатора той же опубликованной версии; ожидающие решения сессии не показываются. Элементы: название (clamp до 2 строк, не растягивает dropdown), аватар и имя сотрудника, время, состояние (pill с иконкой), краткий итог. Поиск на сервере с debounce 250 мс: loading, empty (запрос «xyz»), error с кнопкой «Повторить» (запрос «ошибка»), cursor infinite scroll по 30 элементов. Summary показывает «Продолжение: сессия … · сотрудник · время».
