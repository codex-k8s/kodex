Предпросмотр эффективного доступа

пересчитан
Участник с ролью v3 в Проекте «Корпоративные продажи»:
Итог проверяется сервером при каждом действии; предпросмотр только показывает, что даст роль.
Роль не редактирует сырой список permissions: набор действий фиксирован платформой, каждое действие имеет название, описание и риск.

Редактор пользовательской роли: сохранение создаёт v3, а v2 остаётся у существующих привязок. Область — radio-cards четырёх типов (Organization / Project / тип сущности / конкретная сущность); preset «Один Проект · запуск двух выбранных сотрудников» уже применён: Project + ограничение выбранными ИИ-сотрудниками через inline async picker (серверный поиск, cursor-подгрузка, tray выбранных). Полномочия — группированный чек-лист с русским названием, описанием, риском и областью; только allow. Справа — предпросмотр эффективного доступа, обновляющийся при изменении выбора и чек-листа.
