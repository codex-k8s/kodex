Explain-access: для выбранного участника и области таблица показывает каждое действие с русским названием, описанием, риском, результатом и источником назначения (системная роль, пользовательская роль с версией, OIDC-группа, прямая привязка). Панель «Почему?» разворачивает цепочку вывода для разрешения и для запрета; запрет объясняется отсутствием разрешающей привязки — явных deny в MVP нет. Результат рассчитывается сервером.
