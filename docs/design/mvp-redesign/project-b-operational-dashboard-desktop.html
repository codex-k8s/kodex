Вариант B делит экран на две рабочие колонки: «Работа» — плотная таблица активных и недавних запусков с раздельными колонками «Исполнитель», «Инициатор» и «Источник» (иконка + tooltip) и закреплённым столбцом статуса; «Решения» — открытые Human Gates с кратким effect preview, сроком и одной кнопкой «Рассмотреть», плюс история решений. Показатели Проекта сведены в компактную полосу summary-strip, каждый элемент которой ведёт к отфильтрованному списку. Таблица — срез за период, полный список открывается отдельно с серверным поиском.
