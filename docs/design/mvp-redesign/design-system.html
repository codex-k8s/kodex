Modal · Drawer · Bottom sheet

Вызов
Modal — для решения «здесь и сейчас» (подтверждение, picker). Drawer — для контекстной панели (Kodex, ход работы, детали) — не теряет экран. Bottom sheet — mobile-эквивалент обоих; см. mobile frame ниже. При открытии фокус уходит на первый элемент, Tab зациклен внутри, Escape закрывает и возвращает фокус.

Ключевые controls в тёмной теме · графит без синевы, статусы сохраняют контраст

Дизайн-система — единственный источник токенов и поведения для всех макетов пакета: assets/kodex.css (светлая и тёмная тема, оболочка, controls, состояния) и assets/kodex.js (оболочка, меню, drawer/sheet/modal с focus trap, tabs, segmented, async pickers с cursor-пагинацией, canvas, подсветка кода, синтетические данные). Все controls имеют стабильные размеры, keyboard navigation, видимый фокус, доступные названия и состояния disabled/read-only/error; native <details> как меню не используется. Отличия от старого пакета: помощник вынесен из навигации в FAB и контекстный drawer; переключатель Проекта — внутри навигации, поиск растянут; realtime-индикатор вместо кнопок «Обновить»; source/initiator/executor разделены; добавлены async pickers, tablet-режим и тёмная тема.
