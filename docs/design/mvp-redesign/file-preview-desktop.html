Версия для сотрудника

Предпросмотр открывается как modal--xl поверх списка: слева страница документа, отрисованная платформой (навигация по страницам, масштаб, поиск в документе), справа — сведения. Содержимое не скачивается на устройство и не исполняется; для типов вне безопасного списка показывается понятное ограничение. Назначение сотрудникам — async multi picker с tray выбранных; у каждого назначения видна точная версия. Скачивание — одноразовая ссылка с аудитом. Modal имеет focus trap, закрывается по Escape и возвращает фокус кнопке «Предпросмотр».
