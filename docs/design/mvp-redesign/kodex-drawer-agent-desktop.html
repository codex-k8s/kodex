История диалогов

Тот же drawer в контексте конкретного сотрудника: набор предлагаемых действий отличается от списка сотрудников, а действие «Выдать доступ к GitHub» недоступно по полномочиям (disabled + tooltip, проверка на сервере). Ответ Kodex опирается только на безопасные данные — журнал запуска и метаданные файла; содержимое изолированного файла не читалось. Предложенное действие «Проверить файл заново» создаёт обычную серверную операцию от имени пользователя.
