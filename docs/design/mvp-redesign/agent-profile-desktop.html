Аналитик продаж · вариант 2 из 3
Предпросмотр · изображение проверено · нейтральная пиктограмма без текста и логотипов
Аватар не меняет полномочия, инструкции и доступы сотрудника. Kodex создаёт изображение по назначению и роли; оно сохраняется только после «Применить».

Карточка сотрудника использует вкладки «Профиль / Инструкции / Runtime / Окружение / Доступы и знания». В профиле — редактируемые поля и блок «Аватар»: Kodex предлагает нейтральную пиктограмму с безопасным предпросмотром, варианты можно перебирать, применить, заменить своим файлом или удалить; везде явно сказано, что аватар не влияет на полномочия и инструкции. Без изображения используется fallback с инициалами. Справа — сводка и «Доступы и знания»: только проверенные источники и их версии (никаких chunks, embeddings и vector search в MVP).
