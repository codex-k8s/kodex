Будет записано в аудит: Анна Волкова

Группы — только чтение из Keycloak: состав, время синхронизации и расхождения показаны, но не редактируются. Единственная операция Kodex — привязка группы к роли и области (Организация / Проект / конкретные сущности). Тысячи ролей в Keycloak не нужны: прикладные роли и их версии живут в Kodex, группа провайдера лишь ссылается на них. Группа, отсутствующая в OIDC, помечена состоянием без удаления привязок.
