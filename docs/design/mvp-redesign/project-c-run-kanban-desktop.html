Вариант C для Проектов с большим числом параллельных работ: запуски сгруппированы в колонки «В очереди / Работает / Ждёт решения / Завершён», каждая прокручивается независимо. Карточка показывает название, исполнителя (аватар), инициатора, источник запуска (иконка + tooltip), длительность и — для ожидающих решения — срок и кнопку «Рассмотреть». Фильтры по сотруднику, источнику и периоду применяются на сервере; переключатель «Kanban / Список» меняет представление тех же данных без изменения размеров layout. Ресурсы Проекта сведены в подзаголовок и открываются через навигацию Проекта, чтобы не дублировать быстрые действия.
