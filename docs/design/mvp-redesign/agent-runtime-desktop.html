Runtime показывает раздельно провайдера, пул учётных записей с policy выбора (least_used / weighted / фиксированная привязка), модель, runtime-профиль, окружение и versioned config.toml overlay. Overlay редактируется как TOML и валидируется: попытка отключить enforced политику (например, sandbox_mode) подсвечивается как ошибка и блокирует сохранение. Справа — итоговый effective config без значений секретов (только ссылки) и список защищённых параметров, которые overlay перекрыть не может. Все изменения применяются к следующему ходу через новую RuntimeRevision.
