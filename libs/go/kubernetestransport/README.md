# Kubernetes HTTP transport

`kubernetestransport.New` создаёт отдельный HTTP client с переданным CA pool,
TLS server name, timeout и текстом ошибки redirect. Он устанавливает минимум
TLS 1.3, включает попытку HTTP/2 и запрещает перенаправления. Proxy из окружения
не используется. Клиент не загружает credentials и не выполняет сетевых запросов
при создании; вызывающий владеет остановкой и закрытием простаивающих соединений.

Helper закрыто отклоняет nil CA pool, пустое имя, неположительный timeout и
пустой текст ошибки redirect. Он не проверяет endpoint, содержимое CA pool,
допустимость имени, bearer token или права на ресурс. Вызывающий обязан закрыто
проверить эти значения и получить CA из доверенного источника до создания клиента.
Ошибку redirect и каждый используемый endpoint назначает вызывающий. Этот helper
не заменяет `exactkubernetessecret`: та библиотека также владеет точными ресурсами,
чтением projected token и отдельными лимитами простаивающих соединений.

Unit-тесты проверяют настройки, разные экземпляры, отказ неверного TLS name,
недоверенной CA и перехода по redirect на локальном synthetic TLS server.
Они не подтверждают доступность, RBAC или поведение настоящего Kubernetes API.
