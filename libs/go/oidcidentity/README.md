# oidcidentity

Модуль приводит стандартные OIDC `sub`, `sid` и `jti` к UUID, используемым во
внутренних контрактах Kodex. Уже канонический UUID сохраняется, а opaque
идентификатор детерминированно преобразуется с разделением по issuer и виду
идентичности.

Модуль не проверяет подпись, audience, scope, roles или срок действия токена:
это ответственность verifier вызывающего сервиса. Ошибочный, пустой либо
неограниченный по размеру идентификатор отклоняется без fallback. Модуль не
хранит состояние, не выпускает метрики и не владеет lifecycle.

Изменение namespace UUID или алгоритма преобразования является несовместимым:
оно меняет actor/session/token identity в persisted state и требует отдельной
миграции.
