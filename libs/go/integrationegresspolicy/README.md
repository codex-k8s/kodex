# Сетевой допуск OpenAPI-интеграций

Control-plane формирует документ из разрешённого множества HTTPS origins и
полного свежего проверенного DNS snapshot. Для origin с вращающимися A/AAAA
документ может дополнительно удерживать ранее проверенные публичные адреса
не более двух минут от последнего наблюдения. Общий предел — 32 адреса на
hostname; превышение закрыто отклоняется. Egress-gateway потребляет immutable
документ точного поколения и digest. Профиль предназначен только для отдельного
listener интеграций; обычный CONNECT, STT и mail не получают эти destinations.

В документе нет учётных данных, содержимого OpenAPI или аргументов вызова.
Сохранение разрешения, транзакция владельца, Kubernetes publication, готовность
listener и telemetry принадлежат соответствующим сервисам. Пустой список
origins допустим при первом запуске, но не даёт сетевого доступа.

Изменение schema/digest требует совместного обновления producer и consumer.
Перед каждым CONNECT требуется свежий полный публичный DNS snapshot. Dial
получает только пересечение этого snapshot с адресами опубликованного
документа; новый непроверенный адрес никогда не набирается. Если пересечение
пусто, origin недоступен до следующей публикации. Согласованное владельцем
перекрытие не отменяет TLS, точные SNI/hostname, NetworkPolicy и ограничение
origin. Невалидный hostname, частный/mixed либо устаревший DNS snapshot,
неизвестный порт или несовпавший digest закрыто отклоняются. Ошибки не
содержат адресов.
