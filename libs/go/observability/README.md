# Исполняемая наблюдаемость

Пакет содержит общий ограниченный Prometheus-профиль для Go gRPC
компонентов. Имена операций задаются закрытой картой при сборке;
неизвестный метод нормализуется в `unknown`. Пакет не принимает произвольные
метки из запроса или транспортных метаданных. Streaming RPC получает общий
server-owned correlation UUID, полный span, счётчик завершения, duration и
in-flight gauge; ранний отказ до первого сообщения входит в тот же контур.

Подпакет `errorclass` содержит чистое отображение `Postgres(SQLSTATE)` в
закрытые диагностические классы. Он не импортирует telemetry SDK или
драйвер БД, не принимает error text, не логирует и не выбирает retry.
Вызывающий сначала разрешает типизированную ошибку и сам сохраняет порядок
классификации; неизвестный SQLSTATE всегда превращается в `database`.
