# `artifacttype`

Пакет содержит единый server-side allowlist и закрытое определение формата артефакта по содержимому. Его используют `bot-service` при приёме файлов и `agent-runner` при подготовке manifest и безопасного имени выдачи.

Вход ограничен 8 МиБ. Имя файла, расширение и заявленный Mattermost MIME не участвуют в допуске. Однозначные CSV и Markdown распознаются консервативными проверками содержимого, а неоднозначный UTF-8 остаётся `text/plain`. Архивы и документы остаются непрозрачными: пакет проверяет структуру контейнера и идентификационные записи, ничего не извлекает на диск, не рендерит и не исполняет. OOXML, ODF/OpenOffice и CFB с макросами, VBA, ActiveX, embedded/OLE objects, скриптами или внешними связями закрыто отклоняются.

Основной контракт:

```go
mediaType, err := artifacttype.Detect(readerAt, size)
if err != nil {
    // Содержимое не относится к явно разрешённому формату.
}
extension, err := artifacttype.Extension(mediaType)
```

Полный список MIME и расширений, ограничения контейнеров и ручной сценарий описаны в [`docs/runbooks/bot-service.md`](../../../docs/runbooks/bot-service.md).
